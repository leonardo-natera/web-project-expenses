## Project 7

**JavaScript Expense Tracker**

This project is a responsive expense tracking application developed as an introduction to JavaScript. It allows users to manage a budget, record expenses, and view dynamically calculated financial statistics.

The main goal of this project was to begin working with JavaScript fundamentals and understand how JavaScript can be used to add logic, interactivity, and dynamic data to a web application.

## Features

- Set and manage a budget
- Add new expenses
- Organize expenses by category
- Calculate total expenses
- Calculate average spending
- Display the remaining balance
- Show spending statistics by category
- Identify the category with the highest spending
- Delete individual expenses
- Clear the expense list
- Dynamically update information on the page

## Technologies

- HTML5
- CSS3
- JavaScript
- DOM manipulation
- JavaScript functions
- Arrays and objects
- Event handling
- Git and GitHub

## What I Learned

This project marked my introduction to JavaScript in web development. I practiced working with variables, functions, arrays, objects, events, and DOM manipulation to create an interactive application.

I also learned how to connect application logic with the user interface, calculate values from stored data, and dynamically update page content based on user actions.
